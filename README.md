# 👑 西班牙哈布斯堡王朝：黃金世紀數位講義
> 一個基於「規格驅動開發（Spec-Driven Development）」與 AI 協作所打造的沉浸式歷史數位講義專案。

---

## 📌 專案簡介
本專案為數位講義與 AI 協作實踐作業。與傳統「手刻網頁」或「單次生成網頁（Vibe Coding）」不同，本專案的核心目的在於**建立一套標準化規則與可擴充架構**，讓 AI 能夠在不破壞全站風格與排版的前提下，依循既定規範自動擴充與維護未來的新內容。

* **主題**：西班牙哈布斯堡王朝（1516–1700）歷史長廊
* **核心定位**：純介紹、沉浸式歷史導覽（無考試、無測驗評量），營造西班牙黃金世紀（Siglo de Oro）的古典宮廷氛圍。
* **線上展示**：[點此瀏覽實際網頁成果 (GitHub Pages)](https://kzsdjlhgfzbsdlg.github.io/spanish-habsburgs/)

---

## 🏛️ 視覺設計與互動特色
1. **古典宮廷美學**：採用深緋紅（`#7A1C1C`）、皇室金（`#C59B27`）與羊皮紙米色（`#FAF6F0`）配色，搭配襯線字體（`Noto Serif TC`），重現文藝復興時期的歷史厚重感。
2. **中心貫穿式時間線（Central Timeline）**：頁面正中央有一條金色時間主軸，歷史事件與博物館真跡油畫採用「左右交錯（Zigzag）」排列。
3. **滾動漸顯動畫（Scroll Reveal）**：結合 JavaScript `IntersectionObserver`，隨著讀者向下滑動，歷史事件與名畫會依序優雅浮現。

---

## ⚙️ 專案架構
本專案嚴格實踐 **「資料與視圖分離」**，所有歷史文本與圖片連結皆獨立於資料層，前端透過非同步載入（`fetch`）動態渲染：

```text
spanish-habsburgs/
├── AGENTS.md               # 【核心規範】AI 開發與擴充規則說明書
├── README.md               # 專案說明文件（本檔案）
├── index.html              # 主網頁（含中心時間線與動態渲染邏輯）
├── style.css               # 古典風樣式與捲軸微調
└── data/
    └── ch01-habsburg.json  # 歷史事件、年份、文化說明與博物館真跡圖片資料
